# Проверка E Voice 1.1.0

**19 ноября 2026.** Семь установочных и переносимых пакетов собраны из коммита `a4553f1`. Каждый содержит интерпретатор, движок и русскую модель. Во всех пяти нативных сборках выпуск распознал контрольную речь с отключённой сетью. Тот же Windows EXE отдельно прошёл проверку совместимости на Windows 11 ARM. [Сборка и протоколы на GitHub](https://github.com/moldset-mmc/e-voice/actions/runs/44519633621) · [Машиночитаемые результаты](https://github.com/moldset-mmc/e-voice/releases/download/v1.1.0/QA-v1.1.0.json)

## Что исправлено при аудите

| Участок | Обнаруженное поведение | Исправление и проверка |

| Вставка диктовки | За время распознавания фокус мог перейти в другой редактор, и готовая фраза предназначалась уже другому окну. | В Windows сохраняются HWND и PID при остановке записи. Перед вводом проверяется активное окно. Новая запись отменяет отложенную вставку предыдущей. Последняя фраза доступна для копирования. Есть отдельные тесты на смену окна и задержку из-за модификатора. |
| Настройки и кнопка | При запуске настройка скрытой кнопки и сохранённая позиция переопределялись. Повреждённый JSON мог сорвать запуск. | Видимость и положение восстанавливаются с учётом экрана. Поддерживаемые поля проверяются по типу. Запись настроек использует временный файл и атомарную замену. |
| Микрофоны и память | Устройство должно было поддерживать 16 кГц. Последний аудиоблок выходил за лимит длительности. WAV читается частями, до 20 секунд с одним отсчётом для поиска точки разделения. Проверены совпадение границ с микрофонным режимом и реальная речь при 16 и 48 кГц. |
| Установка на другом компьютере | Комплект зависел от устройства Windows и старого расположения Tcl/Tk. macOS Installer мог выбрать ранее найденную копию приложения. | Проверяется запуск установленного экземпляра. Учтены Tcl/Tk с данными в DLL. Путь Mac-пакета закреплён за папкой «Программы» текущего пользователя. Для Linux проверены DEB и повторная установка архива в домашнюю папку с пробелом в имени. |
| Поставка и зависимости | В прежнем репозитории отсутствовала лицензия авторского кода. Копирование всей рабочей папки модели допускало случайные файлы. PyPI указывал исправления безопасности для используемой Pillow 12.3.0. | Добавлены MIT для E Voice и отдельные уведомления компонентов. Для модели упаковщик разрешает только четыре файла из закреплённого манифеста, сам манифест и лицензию. Проверяются размеры и SHA-256. Pillow обновлена до 13.0.0. Для всех 26 пакетов из lock-файла проверен индекс уведомлений PyPI на дату аудита, активных записей для этих версий не найдено. |

Проверка исходников охватила обработку аудио, отдельный процесс распознавания, хранение настроек, системный ввод, мышь, плавающую кнопку, всплывающие окна, конфигурацию сборки и сценарии установки. Код E Voice не отправляет микрофонные записи во внешний сервис. При штатной диктовке аудио и последний результат находятся в оперативной памяти. На macOS и X11 результат для автовставки помещается в системный буфер, поэтому срок его хранения зависит также от менеджера буфера пользователя. ## Скорость, оперативная память и размер

На Windows x64 в виртуальной машине GitHub измерялась задержка от **остановки записи до готового текста**. На вход подавалась одна секунда речи. Для холодных и тёплых измерений загрузка начиналась за секунду до остановки.

| Состояние | Результат |
| --- | --- |
| Модель уже в памяти, три повтора | 132–145 мс, медиана 133 мс |
| Модель заново загружается с диска, три повтора | 641–1127 мс, медиана 797 мс |
| Начать и сразу остановить без времени на предзагрузку | 1401 мс в одном прогоне |
| Готовность до первой фразы | 52,4 МиБ рабочего набора |
| После распознавания с загруженной моделью | 364,1 МиБ суммарного рабочего набора интерфейса и распознавателя |
| После выгрузки модели через 30 секунд простоя | 60,2 МиБ рабочего набора |

Windows-установщик занимает 182 591 785 байт, около **183 МБ**. Четыре файла модели в распакованном виде занимают 231 897 202 байта. Установка копирует веса один раз. Повторная фраза в течение 30 секунд использует уже загруженную модель. На другом процессоре и диске время будет отличаться. [Размеры и SHA-256 всех пакетов](https://github.com/moldset-mmc/e-voice/releases/tag/v1.1.0)

## Границы выпуска

- Включена русская GigaAM v3. Другим языкам потребуется другая модель. Доли ошибок распознавания на корпусе речи в этом выпуске не измеряли.
- Целевые платформы — современные настольные ОС 64 бит. На Mac проверена версия 15. На Linux использованы glibc 2.35 и графическая сессия. Android, iOS, Windows 7/8 и 32-битные компьютеры потребуют отдельных портов или сборок.
- В Wayland результат доступен через системный буфер и обычную вставку. Глобальный перехват сочетаний и тройного щелчка реализован для X11. Работу с физическими микрофонами, разрешениями macOS и каждым оконным менеджером следует оценивать на целевом компьютере.
- Коммерческая подпись Windows и нотаризация Apple в этот выпуск не входят. Для распознавания в обычных приложениях используются разрешения текущего пользователя. Системные защищённые поля могут блокировать ввод. [Установка и разрешения](README.md#скачать)
