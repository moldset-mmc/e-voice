E Voice 1.1.4 — локальная русская диктовка для Windows, macOS и Linux. Выберите установщик своей системы. Русская модель входит в каждый из семи пакетов и работает без интернета.

- Один тайм-аут охватывает передачу записи и получение текста. Если распознаватель перестал читать аудио, E Voice завершает этот процесс. Следующую запись можно начать из того же приложения.
- На macOS и Linux/X11 новая копия пользователя сохраняется, даже если она сделана сразу после автовставки. Две быстрые диктовки корректно восстанавливают исходный текст буфера.
- Windows EXE включает подписанные Microsoft Visual C++ Runtime и стандартный звуковой драйвер PortAudio. Windows и Mac поставляются без необязательных ASIO DLL. Настройки трея, плавающего микрофона и горячей клавиши наследуются из 1.1.3.
- Для бесплатного или платного распространения вместе с установщиками доступен отдельный файл **E-Voice-1.1.4-Licenses-and-Sources.zip**. В нём находятся фактические уведомления установленных программ, файлы для повторной сборки и исходники зависимостей. Контрольные суммы установщиков и архива перечислены в **SHA256SUMS.txt**.
